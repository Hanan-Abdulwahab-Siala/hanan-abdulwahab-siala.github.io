Hanan Abdulwahab Siala

Reverse engineering software systems

I am a PhD student at King’s College London, under the supervision of Dr. Kevin Lano. My research investigates the use of fine-tuned Large Language Models (LLMs) to automate the extraction of UML class diagrams and OCL constraints from Java and Python source code, evaluating the resulting LLM4Models toolset through a series of case studies and symbolic execution metrics.

RESEARCH

Research areas

Large Language Models (LLMs) for Software Engineering

My research explores the application of large language models to support software engineering activities, with a focus on automating software artifact understanding, transformation, and abstraction. I investigate LLM-based approaches for extracting high-level software knowledge from source code, generating design representations, and bridging the gap between implementation artifacts and software models.

Software Reverse Engineering and Program Understanding

My research focuses on recovering high-level design knowledge and structural information from existing software systems to improve software comprehension, documentation, and maintenance. I investigate AI-assisted reverse engineering techniques for analyzing Java and Python programs, extracting meaningful abstractions, and recovering software models from source code.

Model-Driven Engineering and Software Modeling

My research investigates the use of model-driven approaches for automatically deriving software models from implementation artifacts. In particular, I explore the generation of UML and OCL representations from source code to support model recovery, design documentation, consistency analysis, and improved alignment between software implementations and their conceptual models.
